# Shelf

One storage location drawn as a bookcase shelf: a header, a recessed case and a wooden plank, holding `SpoolSpine`s.

- Provide `name` ("Shelf A"), `meta` ("Dry box 1 · PLA · 18% RH · 14 spools"), and `SpoolSpine` children in shelf order.
- Set `warn` when the location's humidity is too high; the meta line turns oxblood.
- `action` is an optional link on the right, such as "Browse shelf →".
- Leave space at the end of a part-full shelf; don't stretch spines to fill it.
