# Swatch

A filament colour shown on a neutral white disc, so it reads true against the warm paper.

- Provide `hex`; `size` is `sm` (32px, lists and tables), `md` (64px, slot cards) or `lg` (96px).
- Give a `label` when the colour name isn't written next to it.
- Every filament colour in the product goes through a swatch, a spine or the spool drawing. Never paint a filament colour straight onto paper.
