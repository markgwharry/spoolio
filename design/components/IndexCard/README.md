# IndexCard

A spool's catalogue record, styled as a library index card with an oxblood top rule.

- Provide `accession` ("No. 0142 · Shelf A · Dry box 1"), `title` (the colour name), `subtitle` (brand · product · diameter), `status` and `statusTone`, and `fields` as label/value pairs.
- Put a `Meter` in as children; it sits between the header and the ruled fields.
- Fields come in pairs across two columns. Keep an even count and put related pairs side by side (Nozzle / Bed, Acquired / Last dried).
- One index card per page; it holds the page's `display` title.
