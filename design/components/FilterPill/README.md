# FilterPill

A toggle for narrowing the shelves or catalogue by material; the pressed pill is filled in `ink`.

- Provide `pressed` and an `onClick`. Pills in one row act as a single-choice group unless the screen says otherwise.
- Label with the material as people say it: "PLA", "PETG", "Engineering". Start the row with "All materials".
- Keep a row to one line at desktop width; it may wrap on a phone.
