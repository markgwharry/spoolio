# NavItem

A sidebar link to one of the library's rooms, with an optional count on the right.

- Provide `href`, the label as children, `current` on the page being viewed, and a short `count` ("32", "4 out").
- The sidebar order is fixed: Shelves, Catalogue, Circulation, Ledger, Acquisitions, Archive.
- Sits on `paper-sunk`, inside a `nav` with an `aria-label`.
