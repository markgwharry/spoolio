# SpoolDrawing

A face-on drawing of the spool in which the wound filament shrinks with the grams remaining, against a dashed ring showing a full spool.

- Provide `hex`, `remaining` and `net` (default 1000); `size` is the square's pixel size (default 300).
- The radius is area-true, so half the grams draws half the wound area.
- Use it once, large, on a spool's record page, on a `swatch-ground` card with a caption giving the hex.
